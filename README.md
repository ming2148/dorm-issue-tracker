# CondoCare • ระบบจัดการงานซ่อมแซมภายในหอพัก/คอนโด (Dorm/Condo Issue Tracker)

ระบบเว็บแอปพลิเคชันระดับ Enterprise / Production-grade สำหรับบริหารจัดการงานแจ้งซ่อมบำรุงห้องพักคอนโดมิเนียมและหอพัก พัฒนาด้วยภาษา **Go (Golang 1.22+)** บนสถาปัตยกรรม **Clean Layered Architecture**

---

## 🌟 ฟีเจอร์หลักของระบบ (Key Features)

### 1. ระบบยืนยันตัวตนและการแบ่งสิทธิ์ (Authentication & RBAC)
*   **ลูกบ้าน (Resident):** เข้าดูได้เฉพาะรายการซ่อมของห้องตนเองเท่านั้น
*   **นิติบุคคล / ช่างซ่อมบำรุง (Admin & Technician):** ดูภาพรวมงานทั้งหมด เปลี่ยนสถานะ มอบหมายช่าง และบันทึกผลงานซ่อม
*   ความปลอดภัยสูงด้วย **JWT (Access Token & Refresh Token)** ใน HttpOnly Cookies ป้องกัน XSS และ CSRF
*   **Rate Limiter** ป้องกันการโจมตีแบบ Brute Force บนหน้าเข้าสู่ระบบ

### 2. ฟอร์มรับข้อมูล 2 ชุด (User Forms)
*   **Form 1: ใบแจ้งซ่อมปัญหาใหม่ (Repair Request Form)**
    *   หัวข้อปัญหา, หมวดหมู่งานซ่อม (ไฟฟ้า, ประปา, เครื่องใช้ไฟฟ้า, โครงสร้าง, อื่นๆ)
    *   ดึงเลขห้องอัตโนมัติจากเซสชัน (Auto-filled)
    *   ระดับความเร่งด่วน (ปกติ, ด่วน, ด่วนมาก)
    *   อัปโหลดรูปภาพประกอบหลายภาพ (Magic Bytes MIME validation, สุ่มชื่อ UUID, จำกัดขนาด 5MB)
*   **Form 2: แบบฟอร์มประเมินความพึงพอใจและรีวิว (Repair Feedback Form)**
    *   แสดงให้กรอกได้ **เฉพาะเมื่อสถานะงานเป็น "Completed (เสร็จสิ้น)" เท่านั้น**
    *   ให้คะแนน 1-5 ดาว, ความคิดเห็น และการประเมินช่างผู้รับผิดชอบ
    *   ปิดงานซ่อม (Transition to `Closed`) อัตโนมัติหลังรับรีวิว

### 3. การควบคุมความเป็นเจ้าของข้อมูล (Data Ownership & IDOR Protection)
*   ลูกบ้านสามารถ **แก้ไข (Update)** หรือ **ยกเลิก (Cancel/Soft Delete)** ได้ **เฉพาะเมื่อสถานะยังเป็น "Pending (รอดำเนินการ)" เท่านั้น** (หากช่างรับงานไปแล้วจะไม่สามารถแก้ไขหรือยกเลิกเองได้)
*   ป้องกัน IDOR ในระดับ Business Logic ตรวจสอบ `WHERE id = :ticket_id AND user_id = :current_user_id` เสมอ

### 4. หน้าแดชบอร์ดนิติบุคคลและช่าง (Admin & Technician Dashboard)
*   การ์ดสรุปสถิติจำนวนงาน (Total, Pending, In Progress, Completed)
*   กราฟสัดส่วนปัญหาแยกตามหมวดหมู่ (Chart.js)
*   ตารางค้นหาและคัดกรองงานซ่อมแบบเรียลไทม์
*   Action Controls: เปลี่ยนสถานะงาน, มอบหมายงานช่าง, บันทึกหมายเหตุจากช่าง

## 🚀 วิธีการติดตั้งและรันระบบ (Quick Start)

### วิธีที่ 1: รันโดยตรงด้วย Go (Zero-Config SQLite)
ระบบมาพร้อมไดรเวอร์ Pure-Go SQLite ที่ทำงานได้ทันทีโดยไม่ต้องลงฐานข้อมูลเพิ่ม:

```bash
cd dorm-issue-tracker
go run cmd/api/main.go
```
เปิดเว็บเบราว์เซอร์ไปที่: **`http://localhost:8080`**

### วิธีที่ 2: รันด้วย Docker Compose (PostgreSQL Production Setup)
```bash
docker-compose up --build
```
